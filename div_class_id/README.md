# expo_html

## Div

Este <div>elemento se utiliza como contenedor para otros elementos HTML.
El elemento <div>
Por defecto, este <div>elemento es un elemento de bloque, lo que significa que ocupa todo el ancho disponible e incluye saltos de línea antes y después.

## Class

El atributo HTML classse utiliza para especificar una clase para un elemento HTML.
Varios elementos HTML pueden compartir la misma clase.
El atributo de clase
Este classatributo se usa frecuentemente para indicar el nombre de una clase en una hoja de estilos. JavaScript también puede usarlo para acceder y manipular elementos con ese nombre de clase específico.

## Id 

El atributo HTML idse utiliza para especificar un identificador único para un elemento HTML. 
No puede haber más de un elemento con el mismo ID en un documento HTML.
